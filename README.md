# EDA-of-FDA-Approved-Peptide-Drugs
This Project is about the analysis of peptide drug applications for approvals at FDA.

Peptide therapeutics have emerged as one of the fastest-growing classes of pharmaceuticals, offering high target specificity, improved efficacy, and reduced off-target toxicity. Understanding historical approval trends, sponsor activity, formulation preferences, and market dynamics is essential for pharmaceutical companies, researchers, and regulatory professionals.

This project performs an end-to-end Exploratory Data Analysis (EDA) on FDA-approved peptide drugs using publicly available FDA datasets. The analysis integrates multiple FDA data sources, applies comprehensive data cleaning and feature engineering, and uncovers actionable insights into peptide drug approvals, sponsor dominance, formulation trends, marketing status, and industry growth.

This project performs an exploratory data analysis (EDA) and  trend analysis of FDA-approval of  peptide drugs using publicly available FDA regulatory datasets(accessed on 02Feb,2026) to support strategic investment, market competitors, Research and Development decisions.
